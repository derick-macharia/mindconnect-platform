# MindConnect 🌱

An inclusive mental health support platform for Kenyan youth—offering therapy, peer counselling, AI guidance, and educational resources to promote mental wellness, awareness, and healing.

**Tagline:** _“St;ll Here”_ — inspired by the global semicolon movement to remind us that our story isn’t over yet.

---

## 🌍 Overview

MindConnect is a culturally resonant digital platform focused on Kenyan youth aged 18–35. It bridges the gap between therapy, awareness, and daily mental wellness through accessible, holistic tools.

---

## 🌟 Core Features

- 💬 **Licensed Therapy Access** – Connect with professional therapists  
- 🤝 **Peer Counsellors** – Friendly and affordable peer support  
- 🤖 **AI Therapist Assistant** – 24/7 mental health conversations  
- 📓 **Digital Journal & Planner** – A safe space for your thoughts  
- 🔔 **Healthy Habit Reminders** – Web, email, or SMS nudges  
- 💡 **Mental Health Nuggets** – Bite-sized educational content  
- 🎟️ **Wellness Events** – Live or recorded guided sessions  
- 🔒 **Dynamic User Greeting** – Personalized experience via AuthContext  

---

## 🛠 Tech Stack

### 🧠 Backend
- **Framework:** Express.js
- **Database:** MongoDB
- **Auth:** JWT
- **SMS/USSD:** Africa's Talking

### 🎨 Frontend
- **Framework:** React + Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide
- **State:** Context API
- **Persistence:** LocalStorage
